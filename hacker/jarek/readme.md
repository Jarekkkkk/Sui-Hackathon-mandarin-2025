# Zing — The Creator Ownership Protocol

## 📖 項目介紹

我們相信當前的網絡架構從根本上是有缺陷的 —— 它從未為「身份層」（Identity Layer）而設計。任何人都可以創建無數帳號，卻無法證明帳號背後的真實身份與作品歸屬。結果，創作者在中心化平台上創作的大量內容，隨時可能被刪除、限流、或失去收益權，完全喪失了可驗證的所有權與來源。

**Zing 協議** 致力於透過區塊鏈的安全性與 Sui 網絡的高效性能，構建一個可驗證、以創作者為中心的去中心化身份層。當創作者能以密碼學方式將其 Web2 帳號（如 Twitter、Medium、Substack 等）與鏈上身份綁定時，每一份作品終於能被確權、可追溯，並在創作者自己的條件下實現價值變現。

## 🏗️ 協議架構

Zing 採用三層協議架構，從身份到變現，再到內容發現，全面重塑創作者經濟的基礎設施：

### 🧱 1. 身份與所有權層（Identity & Ownership Layer）
- 透過客戶端加密證明（ZKTLS），將創作者的 Web2 帳號與 Web3 身份鏈接起來
- 每一份 Web2 或 Web3 內容都會透過 Walrus 註冊上鏈，達成不可篡改的著作權保護與來源追溯

### 💰 2. 智能變現引擎（Smart Monetization Engine）
- 支援靈活的收入模式（訂閱、贊助、單次付費等），並同時支援法幣與加密貨幣雙軌支付
- 創作者可自由設定價格規則，只需為實際使用部分付費，並因區塊鏈支付高效節省手續費

### 🌐 3. 統一發現平台（Unified Discovery Platform）
- 透過 Chrome 擴充套件提供一鍵內容遷移、贊助與追隨功能
- 同時在新分頁中提供個人化的創作者內容聚合流（類似 daily.dev，但聚焦創作者內容）

### 🚀 我們的願景

我們相信 Zing 能成為創作者經濟的新基礎設施：

- **從身份確權出發**：讓每位創作者真正擁有自己的數位作品
- **透過低費用、高效率的變現模型**：提升創作者收益
- **憑藉鏈上身份網絡的網路效應**：打破平台壟斷，讓創作者能「釋放作品、掌握所有權」
